# karabas-go-gopher: план

Статус 2026-11-25: план утверждён пользователем (решения в разделе 7), AY-бэкенд исключён. Рабочее имя репозитория — `karabas-gopher` (возможно), на GitHub пока не выкладываем.

## 1. Цель

Свой Gopher-браузер для TS-Conf (`.spg`), по функциям не хуже `gopher_esp32.spg` v0.3 от AlexSpawn (исходников нет), но с отдельным сетевым слоем: автодетект и выбор бэкенда, управление Wi-Fi на каждом бэкенде, настройки в INI-файле на SD.

### Что умеет v0.3 AlexSpawn (по строкам бинарника)

- Меню Gopher, ввод URL (`[D]URL`), назад (`[BS]Back`), режим (`[S]Mode`), перезапуск, домашняя `gopher://alexspawn.ru`.
- Поиск (тип 7, `Enter query:`), ввод RUS / ENG (`[INS]`).
- Скачивание на SD в `/downloads` (`Save as:`, mkdir, отмена по BREAK, скорость kb/s / mb/s).
- Просмотр SCR, проигрывание PT3 (AY), MOD через GS, XM через плеер ZiFi32 (`XM: too big for ZiFi32!`).
- Wi-Fi: скан, выбор сети, пароль, подключение (CAPS при старте), «already connected».
- Детект ZiFi32 / GS / TS / SD, синхронизация времени («Try to sync time...»).
- Только ZiFi32 (SPI ESP32). Наша бинарная заплатка (A1/A3/A4 → A0/A1/A2, 0x28 → 0x22) нужна из-за перенумерации команд и несуществующей команды 0x28.

## 2. Железо: плата × бэкенд

| бэкенд | как подключён | Go | Mini | Mini G |
|---|---|---|---|---|
| ZiFi32 (ESP32-S3, прошивка tslabs) | SPI #57 / #77, `ESP32_SPI` в tune.v | — | — | да |
| ZiFi (ESP8266, AT, 115200 + CTS) | `zifi.vhd`: #C7EF команда, #BFEF данные, #C0EF / #C1EF FIFO | да | да | пины UART есть в топе; есть ли модуль на плате — проверить |
| USB serial | TS RS232 #C2EF / #C3EF или EVO 16550 #F8EF..#FFEF → MCU → USB CDC if02 / USB-UART адаптер в хабе | да | да | да |

Факты из кода (2026-11-25):
- ZiFi32 по SPI (`SET_AP_NAME` / `SET_AP_PWD` / `AP_CONNECT` → `TASK_CONN` → `wifi_connect`) **не сохраняет** сеть в NVS; в NVS пишет только консоль ESP (UART0). Значит для ZiFi32 INI на SD — единственное хранилище настроек (как и просил пользователь).
- ESP8266 настраивает boot-ядро (fw `app_wifi`): `AT+CWJAP` (сохраняется во flash ESP), `AT+CWAUTOCONN=1`, `AT+UART_DEF=115200,8,1,0,2`. После старта tsconf ESP8266 обычно уже в сети.
- USB CDC0 (if00) не годится для бинарных данных (парсер AT+KARABAS, DIAG, пейсинг); чистый канал — if02 или USB-UART адаптер ([[usb-second-cdc]], fw #157).

## 3. Архитектура

Два протокольных драйвера, не четыре:

```
 UI (текстовый режим TS 80x30, шрифт 866)
   │
 gopher: URL, разбор меню, история, закладки, поиск, загрузки, просмотрщики
   │
 net API ── caps (XM-плеер, NTP, скан, ...)
   │   open(host, port, selector, query) → read(buf) → close
   │   wifi_status / scan / join(ssid, pwd) / forget / ip
   ├── drv_zifi32: уровень URL (SET_URL, GOPHER_STREAM_START, STREAM_READ, STREAM_CLOSE,
   │               GOPHER_GET + TRACK_* для XM), Wi-Fi по SPI
   └── drv_at:     уровень сокета (AT+CIPSTART / CIPSEND / +IPD / CIPCLOSE, CWLAP, CWJAP)
         поверх byte transport:
         ├── tr_zifi  : ZiFi FIFO #C0EF / #C1EF, 115200, аппаратный CTS
         └── tr_rs232 : TS RS232 FIFO #C2EF / #C3EF (или EVO 16550) → if02 / адаптер
```

### Автодетект (без разрушений)

Порядок: бэкенд из INI (если задан и отвечает) → ZiFi32 (`GET_VER` + `GET_INFO_STR` с таймаутом; только если SPI отвечает) → ZiFi (`AT` → `OK`, затем `AT+GMR` для версии AT 1.x / 2.x) → USB serial (`AT` → `OK`). Список найденных показываем, выбор вручную всегда доступен (экран «Подключение»).

Запрещено при детекте и работе: `AT+RESTORE`, `AT+UART_DEF`, `AT+RST`, `ATE*` с сохранением. Смена скорости только `AT+UART_CUR` (не сохраняется). Сначала используем текущую ассоциацию (`AT+CWJAP?` / `GET_NETSTATE`), только при её отсутствии предлагаем скан.

### Wi-Fi по бэкендам

| | статус | скан | подключение | забыть | где хранится |
|---|---|---|---|---|---|
| ZiFi32 | `GET_NETSTATE`, `GET_IP` | `WSCAN` | `SET_AP_NAME/PWD` + `AP_CONNECT` | `AP_DISCONNECT` | INI на SD (+ автоподключение при старте браузера) |
| ESP8266 (ZiFi / адаптер) | `AT+CWJAP?`, `AT+CIFSR` | `AT+CWLAP` | `AT+CWJAP` (+ `AT+CWAUTOCONN=1`) | `AT+CWAUTOCONN=0` + `AT+CWQAP` | flash ESP (как boot-ядро); в INI только выбранный бэкенд |
| USB serial + PC | у PC-помощника своя сеть: экран показывает «сеть хоста» | — | — | — | — |

### INI

Один файл на SD, `/zifi/gopher.ini`; образца старого клиента нет, формат свой (решение 2026-11-25):

```
[net]
backend=auto
[zifi32]
ssid=...
password=...
autoconnect=1
[gopher]
home=gopher://alexspawn.ru
charset=utf8
downloads=/downloads
```

Комментарии — только отдельной строкой (`;` или `#`): после значения их нет, в пароле может быть `;`. Новый файл создаётся с комментариями о допустимых значениях. Регистр имён секций и ключей не важен, порядок и комментарии пользователя при записи сохраняются.

Пароль в открытом виде, как в INI старых клиентов (на SD больше ничего не защитить). Закладки и история — отдельный файл `bookmarks.txt` (строки `URL<TAB>имя`).

## 4. Опыт ZiFi32 и PR к tslabs

Состояние на 2026-11-25: tslabs/zx-evo **#94** (19 коммитов: зависания, утечки, границы, сетевые задержки) и **#95** (документ протокола) **открыты, не слиты**. На нашей Mini G стоит прошивка 7f0aa09 из `karabas/esp32-fixes`; у других пользователей — апрельская или июльская upstream. Отсюда правила клиента:

1. **Работать на уже прошитом** (апрель / июль upstream / наш форк). Перепрошивка ESP на Mini G = вскрытие корпуса.
2. **Версию определять по `GET_VER` (VER0..2) + `GET_INFO_STR`**, не по `API_VER`: в июле TRACK_* перенумеровали при API 1. Для XM: таблица кодов по версии; неизвестная версия → XM выключен (остальное работает).
3. **Никаких неописанных команд** (0x28 AlexSpawn в форке alexkorochinskiy = VFS SMB). Размер файла — из `DATA_SIZE` ответа `GOPHER_GET` / `GOPHER_STREAM_START` (что стрим gopher отдаёт в total size — проверить, вероятно 0 = неизвестно → прогресс без процента).
4. **Upstream-заклинивание `is_busy`** после stream / gopher (без #94 ESP глотает все команды до выключения): таймаут на каждую команду, экран «ZiFi32 не отвечает» с предложением сброса (`0xEE`, как ts-bios «ESP32 Reset»), без бесконечных циклов.
5. **Стрим закрывать перед новым**, объекты `GOPHER_GET` удалять (`DELETE_OBJECT` / `KILL_OBJECTS`), не копить PSRAM.
6. **Таймаут S2M клиента не короче ~2 с** (у AlexSpawn ~1.7 с рвал стрим), но и не бесконечный.
7. **Разбор селектора в прошивке** (`gopher_client.cpp` ~126-186, `stream_client.cpp` ~411): срезает `T/`, потом шлёт `"/" + селектор`. Селектор, начинающийся с `/`, проходит точно; без `/` (`gopher://host/1foo`) уходит `/1foo` — сломан. Запрос поиска: TAB можно передать сырым байтом в `SET_URL`. Клиент: такие ссылки через ZiFi32 помечать «не поддерживается этой прошивкой».
8. **Предложения в upstream** (через наш форк, после #94, только с согласия пользователя): разбор URL по RFC 4266 (тип, `%09`, без лишнего `/`); команда сохранения сети в NVS по SPI; честный размер для gopher. Клиент от них не зависит.

## 5. Варианты и рекомендации

### A. Язык и сборка
- **A1 (рекомендую): C, SDCC 4.2 + своя минимальная библиотека** по образцу tslabs SDK (`lib/esp32`, `lib/zifi`, `lib/tsconf`), собранная на Linux из исходников; Makefile, свой упаковщик SPG на Python (у нас уже есть разборщик `spgtool.py`). Урок ftview: готовые `.lib` SDK собраны под старую конвенцию вызовов (`--sdcccall 0`) — либо пересобрать их, либо не брать.
- A2: ассемблер sjasmplus — быстрее и меньше, но разбор меню, INI, FAT и UI на асме дольше в разы.
- A3: z88dk — хорошая libc, но нет готовой поддержки TS-Conf / SPG.

### B. FAT на SD
Petit FatFs из SDK (R0.03) не создаёт файлы и не меняет их размер — для INI и `/downloads` не годится. **Рекомендую FatFs R0.15 (ChaN) в урезанной конфигурации** (без LFN или с LFN 866, без f_mkfs): ~12-15 КБ кода, страница памяти TS-Conf.

### C. Дальний конец USB serial
- **C1 (рекомендую): PC-помощник на Python** (`tools/at_proxy.py`), эмулирующий подмножество AT ESP8266 (`CIPSTART` / `CIPSEND` / `+IPD` / `CIPCLOSE`, `CWJAP?` → «сеть хоста»). Тот же `drv_at`, и он же — стенд для отладки без ESP и без платы (host-тесты).
- C2: реальный ESP8266 на USB-UART адаптере в хабе платы — тот же драйвер, ничего писать не надо, только проверить.
- C3: SLIP / PPP — избыточно.

### D. AY-бэкенд
Исключён пользователем 2026-11-25 (драйвер AY 9600 и бывшая Ф6 не делаются).

### E. Кодировки
Шрифт 866. Gopher-серверы русских сайтов отдают UTF-8, иногда CP1251 / KOI8-R: перекодировка в 866 по таблицам, выбор в INI и горячей клавишей, автоугадывание по первой странице (backlog).

## 6. Фазы (одна ветка + один PR на фазу)

- **Ф0. Инфраструктура.** Makefile (SDCC), упаковщик SPG, минимальный crt0 / библиотека TS-Conf, host-тесты (gcc: разбор меню, INI, URL, AT-парсер), `tools/at_proxy.py`. Запуск в эмуляторе без экрана пользователя (unreal-ng TS-Conf, [[emu-shot]]); есть ли там ZiFi — проверить. Итог: «Hello» spg на Mini G.
- **Ф1. Каркас.** Текстовый режим 80x30, клавиатура, строка ввода (RUS / ENG), FatFs, чтение / запись INI, экран настроек. Сделано 2026-11-25: банки кода по 32 КБ (FatFs R0.15 с LFN под SDCC = 27 КБ, в 32 КБ без банков не помещалась вся программа), раскладка памяти — `CLAUDE.md`.
- **Ф2. net API + `drv_at` + `tr_rs232` + `tr_zifi`.** Детект, экран «Подключение» (список найденных, выбор), Wi-Fi ESP8266 (статус / скан / пароль / забыть по правилам `app_wifi`). Проверка: PC-помощник через if02, ESP8266 платы.
- **Ф3. Gopher.** Разбор меню (типы 0 1 7 9 g I h i s +, URL:), навигация, история, домашняя, закладки, ввод URL, поиск, просмотр текста с прокруткой, кодировки.
- **Ф4. `drv_zifi32`.** Детект версии, стрим gopher, Wi-Fi по SPI + INI + автоподключение, таймауты / сброс (раздел 4).
- **Ф5. Файлы и медиа.** Загрузка в `/downloads` (Save as, прогресс, BREAK), SCR, PT3 (AY), MOD через GS, XM через ZiFi32 (`GOPHER_GET` → `TRACK_INIT` / `PLAY`), большие файлы — на SD потоком.
- **Ф6. Время и релиз.** Синхронизация времени (ESP8266 `AT+CIPSNTPTIME?` / ZiFi32 — что есть), README (ru / en), `software/` в karabas-go, howto.

## 7. Решения пользователя (2026-11-25)

1. Язык: C на SDCC (A1).
2. USB serial: PC-помощник `tools/at_proxy.py` (C1) и реальный ESP8266 на USB-UART адаптере (C2), один драйвер.
3. INI: без образца, формат из раздела 3.
4. AY-бэкенд и его фаза исключены.
5. Репозиторий пока только локальный; имя не решено (вариант `karabas-gopher`, без `go`).
